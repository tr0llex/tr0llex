# Соглашения репозитория

Правила одинаковы во всех проектах samoy.love. Файл лежит в корне каждого
репозитория — если правите его, правьте везде.

Здесь только текст профиля: ни выкатки, ни тестов, ни nginx в этом
репозитории нет, поэтому соответствующих разделов общего файла тут нет тоже.
Всё остальное действует без изъятий.

## Коммиты

**В коммитах не должно быть упоминаний ИИ.** Никаких трейлеров
`Co-Authored-By: Claude`, никаких «generated with» в сообщениях коммитов,
описаниях PR и релизных заметках. Это личные проекты и публичное портфолио —
авторство принадлежит владельцу репозитория.

Сообщения — на русском, повелительным наклонением, первая строка до 72
символов и без точки. Тело объясняет **почему**, а не пересказывает диф.

Правило проверяется машиной, а не только совестью: задача `commits` в CI
валит сборку на любом упоминании ИИ. Локально то же самое ловит хук — он
включается один раз на репозиторий, клоном не переносится:

```bash
git config core.hooksPath .githooks
```

Не коммитим чужие изменения: перед коммитом смотрим `git status` и добавляем
только свои файлы. `git add -A` в грязном дереве запрещён.

## Ветки

Работа идёт в ветке, `main` защищён. Мерж — после зелёного CI.

## Структура

```
README.md          английский, единственный markdown в корне вместе с
README.ru.md       русской версией
README.<lang>.md   исключение: языковые версии README ищутся именно в корне
assets/            картинки профиля
```

Журналы изменений в README не ведём — для этого есть история git.
Планы и идеи — в issues, а не в файлах.
